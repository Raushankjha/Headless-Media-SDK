# Headless component documentation

`@headless-media/media-ui-react` exposes behavior-only hooks:

- `useMediaGrid` — grid roles/props and infinite-scroll sentinel behavior.
- `useLightbox` — dialog state, Escape handling, and focus restoration.
- `useReelSwiper` — vertical snap-oriented reel behavior and active-item detection.

The consumer owns all markup and CSS.
